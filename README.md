# Royal Cricket Store — Software Testing Portfolio

## Project overview
This repository contains QA documentation prepared for the Royal Cricket Store e-commerce application.

## Documents
- **Test Plan** — testing objectives, scope, strategy, resources, and planned White Box and Black Box testing.
- **White Box Test Cases — Phase 1** — test cases covering authentication, product retrieval, and product search.
- **White Box Test Cases — Phase 2** — test cases covering cart operations, price calculation, order creation, and profile updates.
- **Bug Reports** — documented defects with summaries, reproduction steps, severity, environment, and status.

## Skills demonstrated
- Manual software testing
- White Box and Black Box testing concepts
- Test planning and test case design
- Test execution and result documentation
- Defect reporting and severity assessment
- Functional testing
- E-commerce application testing

## Project context
The test documentation references a Flask-based e-commerce application using MongoDB. Test results and bug statuses are recorded in the attached documents.
